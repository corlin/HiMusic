# HiMusic

[English](README.md) · **简体中文**

### 家里的无损音乐，在每一块屏幕上自然流动。

HiMusic 把连接在家庭路由器上的 USB 硬盘变成全家可用的私人音乐库。它通过 SMB 直接读取音乐，播放 FLAC 等本地音频，不要求购买 NAS，也不依赖云账号或常开媒体服务器。

![HiMusic macOS 资料库与高解析波形界面](artifacts/design-qa/implementation-option-1.png)

## 一份曲库，覆盖每块屏幕

HiMusic 正在作为同一款产品覆盖 **Windows、macOS、iOS、Android 和 Android TV / Google TV**。每台设备读取同一个家庭音乐目录，同时保留自己的播放队列、音量和收听进度，家人之间互不干扰。

| 平台 | 产品体验 | 当前原型状态 |
| --- | --- | --- |
| macOS | 完整桌面资料库和音频输出选择 | Release 构建已通过，并用本地 FLAC 验证播放和波形 |
| Windows | 键鼠操作的桌面资料库 | 已包含工程入口，仍需在 Windows 开发机验证 |
| iPhone / iPad | 触控优先的个人播放器 | 模拟器构建已通过；设备导入和后台播放仍在规划中 |
| Android | 触控优先的个人播放器 | 已生成 Debug 构建，仍需 Android 真机验证 |
| Android TV / Google TV | 适合客厅远距离观看的大屏播放器 | 已有电视布局，遥控器操作和真实电视播放仍待验证 |

## 现在可以做什么

- **播放路由器硬盘：**连接 SMB 2/3 共享，例如中兴问天 BE7200 MAX 路由器所挂载的 USB 硬盘。
- **播放本地目录：**直接打开桌面电脑里的音乐文件夹。
- **保留原始音频：**通过范围读取传输 FLAC，由客户端解码，不经过服务器转码。
- **看清音乐细节：**显示平滑的高解析动态波形，支持局部缩放、整曲概览以及点击或拖动跳转。
- **完整播放控制：**播放、暂停、切歌、定位、读取失败重试，以及每台设备独立的播放队列。
- **管理聆听设备：**调节应用音量、静音和恢复，并进入符合各平台习惯的音频输出选择。
- **适应不同空间：**桌面使用紧凑资料库布局，电视模式提供更大的字号和操作区域。
- **保护源曲库：**SMB 只读访问，原型不会删除、重命名或改写音乐文件。

## 为简单的家庭环境而设计

```text
USB 共享硬盘
      │
支持 SMB 的家庭路由器
      │
      ├── macOS / Windows
      ├── iPhone / Android 手机
      └── Android TV / Google TV
```

HiMusic 没有强制的中央播放会话：一个人可以在电脑听歌，另一个人同时在电视播放不同专辑。路由器只负责共享文件，无需安装 Docker、Navidrome 或转码服务。

## 当前产品边界

HiMusic 0.3.0 是可以运行的产品原型，还不是应用商店正式版本。基于标签的艺术家和专辑资料库、持久化收藏与歌单、手机后台控制、家庭账号同步、离线下载和手机遥控电视仍在后续规划中。路由器并发读取、电视遥控器导航、休眠恢复和不同设备的高清音频输出也需要实机验证。

HiMusic 会读取原始 FLAC 数据，但这本身不代表最终输出一定 bit-perfect；实际音频链路仍由操作系统和播放设备共同决定。

## 运行原型

项目当前使用 Flutter 3.47.2。

```sh
./scripts/flutter.sh pub get
./scripts/flutter.sh run -d macos
```

构建 Android / Google TV 调试包：

```sh
./scripts/flutter.sh build apk --debug
```

进入应用后，可选择“打开本地目录”读取电脑里的音乐，或选择“连接 SMB 共享硬盘”访问路由器硬盘。SMB 密码只保留在当前会话内，不会写入磁盘。
