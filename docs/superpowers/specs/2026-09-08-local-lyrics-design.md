# HiMusic 本地歌词设计

日期：2026-09-08

## 目标

HiMusic 在播放本地目录、用户选择的文件或 SMB 共享中的歌曲时，显示音乐文件内嵌歌词或同目录同名 `.lrc` 歌词。带时间标签的歌词随播放进度逐行高亮并自动滚动；纯文本歌词保持可读。首版不访问在线歌词服务。

## 产品范围

首版支持：

- 音乐文件中的同步歌词和纯文本歌词；具体可读标签由解析器能力决定，并由样本测试固定。
- 与歌曲同目录、主文件名相同的 `.lrc` 文件，扩展名匹配不区分大小写。
- 标准 LRC 时间标签 `[mm:ss]`、`[mm:ss.xx]`、`[mm:ss.xxx]`，一行多个时间标签，以及 `[offset:+/-毫秒]`。
- LRC 信息标签 `[ar:]`、`[ti:]`、`[al:]`、`[by:]`；这些标签不作为歌词正文显示。
- UTF-8、带 BOM 的 UTF-8；中文常见非 UTF-8 文件在解码失败时尝试 GB18030。
- 同步歌词高亮、自动居中、点击歌词跳转、用户滚动后延迟恢复跟随。
- 没有时间标签时显示可滚动全文；无可用歌词时显示明确空状态。

首版不支持在线搜索、翻译歌词、逐字歌词、桌面歌词、卡拉 OK 动画和歌词编辑。

## 来源与优先级

歌词按以下顺序选择：

1. 音乐文件内嵌的同步歌词。
2. 同目录同名 `.lrc`。
3. 音乐文件内嵌的纯文本歌词。
4. 无歌词状态。

选择同名文件时使用歌曲主文件名进行精确匹配。例如 `夜航.flac` 匹配 `夜航.lrc`，不自动模糊匹配 `夜航 (Live).lrc`。这样可以避免版本错误。

本地目录和 SMB 来源可以列出歌曲所在目录并读取同名 `.lrc`。iOS、Android 的文件选择器必须允许用户同时选择音乐与 `.lrc`；`SelectedFilesSource` 对列表仍只公开音乐条目，但保留已授权的歌词文件供内部匹配。未被用户选择的 iOS 文件不尝试越权读取。

## 数据模型

歌词使用独立模型，避免与歌曲资料中的“作词者”混淆：

```dart
enum LyricsSource { embeddedSynced, sidecarLrc, embeddedPlain }

class LyricsDocument {
  final LyricsSource source;
  final List<TimedLyricLine> lines;
  final String? plainText;
  final Duration offset;
}

class TimedLyricLine {
  final Duration timestamp;
  final String text;
}
```

`LyricsDocument.lines` 按时间稳定排序。相同时间的多行保留原始顺序。空歌词行可以参与时间推进，但界面不绘制无意义的连续空行。

## 组件边界

- `LyricsRepository`：按当前歌曲协调缓存、内嵌歌词和同名文件，不包含 UI 逻辑。
- `EmbeddedLyricsReader`：通过 `MusicSource` 范围读取音乐元信息，输出同步或纯文本歌词。
- `LrcParser`：只负责字节解码、标签解析、偏移应用和规范化，可独立单元测试。
- `LyricsController`：观察当前歌曲与播放位置，加载文档并计算当前行；通过可监听状态暴露加载、成功、空和失败状态。
- `LyricsView`：负责显示、滚动、点击跳转和无歌词提示，不直接访问文件。

歌词能力不得让 `PlayerController` 承担解析细节。播放器只向歌词控制器提供当前曲目、来源、播放位置和 seek 操作。

## 数据流

当前歌曲变化时，`LyricsController` 取消上一首歌曲尚未完成的加载，以来源命名空间、歌曲路径、文件大小和修改时间组成缓存键。`LyricsRepository` 依优先级读取歌词并返回统一文档。同步歌词显示后，控制器根据 `positionStream + offset` 找到最后一个不晚于当前播放位置的行。

快速切歌时，旧任务即使晚返回也不能覆盖新歌曲状态。来源断开或切换时清除当前歌词；缓存可以保留受上限约束的解析结果。

## 界面行为

### 手机

点击底部播放器的歌曲区域进入全屏播放页。页面提供“封面”和“歌词”两个可横向切换的视图；播放器上的歌词按钮直接进入歌词视图。

当前歌词行使用主题强调色和较大字号，前后歌词降低亮度。当前行尽量位于垂直中线稍上方。用户手动滚动后暂停自动跟随，并显示“回到当前歌词”；停止交互约四秒后自动恢复。点击带时间的歌词行调用播放器 seek。

### 桌面与宽屏

展开播放器时，左侧显示封面和歌曲资料，右侧显示歌词。窗口较窄时退化为与手机一致的单栏切换视图。底部播放器保留歌词入口。

### 状态

- 加载：显示低干扰进度提示，不阻塞播放。
- 无歌词：显示“暂无歌词”，并保留封面、标题和创作者信息。
- 纯文本：显示全文，不提供点击跳转和当前行高亮。
- 读取失败：显示“歌词无法读取”，允许重试；失败不影响播放和歌曲元信息。

## 缓存与性能

解析后的歌词采用内存 LRU 缓存，首版上限 128 首。单个歌词文件读取上限 2 MiB，超过上限按失败处理。播放进度变化只计算当前行索引，不重复解析文件；使用二分查找处理跳播，连续播放时允许从当前索引向后推进。

歌词列表只构建屏幕附近的行。自动滚动应避免每次播放器进度事件都触发布局，仅在当前歌词行变化时滚动。

## 错误与兼容规则

- 无法识别的 LRC 行作为纯文本保留；若文档中至少有一个合法时间标签，则无时间标签的普通行不参与同步列表。
- 应用 `[offset:]` 后小于零的时间截断为零。
- 重复时间标签不去重，避免丢失对唱或翻译行。
- 空文件、只有信息标签的文件和解码失败均视为无可显示歌词。
- 文件名匹配和扩展名判断不区分大小写，正文保持原始大小写。
- SMB 读取失败沿用来源层错误语义，不泄露主机、账号或文件路径到用户提示。

## 测试与验收

单元测试覆盖：

- 各种时间精度、多时间标签、offset、信息标签、空行和非法行。
- UTF-8 BOM、GB18030、空文件和大小上限。
- 来源优先级、同名匹配、缓存失效和快速切歌竞态。
- 当前行计算、跳播、歌曲结束和负偏移。

界面测试覆盖：

- 手机宽度下封面/歌词切换无溢出。
- 当前行高亮、用户滚动暂停跟随、恢复跟随和点击跳转。
- 纯文本、无歌词、加载失败状态。
- 桌面宽屏双栏和窄屏单栏。

端到端验收使用至少三首真实样本：内嵌同步歌词、同名 LRC、无歌词。分别在 macOS 和 `corlin17mx` 上验证；SMB 样本还需验证歌词与音频均通过只读范围读取，切歌后旧歌词不会残留。
